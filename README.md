# Twitch notification bot

Этот проект нужен для отображения уведомлений о начале трансляций на платформе twitch в телеграм боте. 
Пользователь сам добавляет и редактирует свой список уведомлений. Таким образом, больше не нужно проверять
каналы каждого отдельного стримера.

## Возможности

- Добавление, удаление, редактирование списка стримеров
- Вкл/выкл уведомлений об окончании трансляций
- Очистка чата от технических сообщений от бота(не чистятся сообщения о добавлении и удалении стримеров, 
а также о начале трансляций)

## Технологии

    - Java 23
    - Maven
    - Telegram API, Twitch API, Hibernate, lombok
    - Data Base: PostgreSQL
    - Docker, Docker Compose

## Получение ключей

### Ключ для telegram бота

Чтобы создать telegram bot, и взаимодействовать с ним, необходимо зайти
в официальный бот по их созданию: @BotFather
Далее пишем "/start" и следуем инструкциям. По итогу у вас должен быть токен бота. 

### Ключи для twitch API

Для этого необходимо перейти на сайт разработчиков твича: https://dev.twitch.tv/docs/authentication/register-app/
После следуйте инструкциям. В итоге вы будите иметь client id и client secret.

### Передача ключей в код

В проекте в пути src/main/resources имеется файл example.source.json. Измените имя, оставив source.json.
Далее откройте этот файл, и подставьте во все поля ваши токены. Далее программа сама получит все необходимые токены,
и будет сама взаимодействовать с twitch.

## Сборка и запуск

Запуск приложения происходит с помощью Docker. Для этого понадобится 
     -Docker
     -Docker Compose
Гайд по установке с официальнго сайта: https://docs.docker.com/get-started/get-docker/

### Запуск через сборку docker вручную
В командной строке:

        -cd 'укажите свой репозиторий'
        - git clone https://github.com/Dronnoon/TwitchNotBot_Telegram.git
        - docker compose build
        - docker compose up -d
        - docker compose logs -f

### Запуск через скрипт в Linux

Можно просто запустить скрипт twitchNotBot.sh
В bash пишем:

    - chmod +x twitchNotBot.sh
    - ./twitchNotBot.sh

### Запуск через скрипт в Windows
    Просто запускаем двойным кликом по twitchNotBot.bat, или прописываем запуск в командной строке
